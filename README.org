# Calendar Slot Finder

An interactive tool to find empty time slots in your calendar by integrating with org-agenda-files and org-gcal entries.

** Features
:PROPERTIES:
:CUSTOM_ID: features
:END:
- 🗓️ Integrates with org-mode agenda files
- 📅 Supports org-gcal Google Calendar integration
- ⚙️ Interactive configuration for working hours and restrictions
- 🔄 Weekly recurring restrictions (e.g., meeting hours)
- 🛡️ Meeting cushion/buffer time (customizable, default 15 minutes)
- 📊 Smart conflict detection and free slot identification
- 🎯 Configurable minimum slot duration
- 📋 Clean output with duration information
- 📧 **NEW: One-press email suggestion with clipboard copy**
- 📝 **NEW: Automatic org entry creation in inbox**

** Installation
:PROPERTIES:
:CUSTOM_ID: installation
:END:
1. *Save the Python script* as =calendar_slot_finder.py= in your preferred directory
2. *Save the Elisp file* as =calendar-slot-finder.el= in your Emacs configuration directory
3. *Add to your Emacs configuration*:

#+begin_src elisp
;; Add to your init.el or .emacs
(add-to-list 'load-path "/path/to/your/elisp/files")
(require 'calendar-slot-finder)

;; Optional: Configure default settings
(setq csf-python-script-path "/path/to/calendar_slot_finder.py")
(setq csf-default-week-offset 1)  ; 1 = next week
(setq csf-working-hours '("09:00" "17:00"))
(setq csf-min-slot-duration 60)  ; minutes
(setq csf-meeting-cushion 15)    ; buffer time before/after meetings
(setq csf-inbox-file "~/Documents/0Inbox/index.org")  ; where to create meetings
#+end_src

** Usage
:PROPERTIES:
:CUSTOM_ID: usage
:END:

*** Quick Workflow (Recommended)
:PROPERTIES:
:CUSTOM_ID: quick-workflow-recommended
:END:

1. *Find free slots*
   #+begin_src elisp
   M-x csf-find-slots-next-week
   #+end_src

2. *Review results* - Shows all available slots with indices [0], [1], etc.

3. *Press ~c~* - Copy email suggestion and create org entries

4. *Follow the prompts*
   - Select first slot index (e.g., 1)
   - Select second slot index (e.g., 3)
   - Enter meeting duration (press Enter for default 30 minutes)
   - Enter who the meeting is with (name, team, or organization)

5. *Results*
   - ✅ Email suggestion copied to clipboard
   - ✅ Two tentative meeting entries created in your inbox org file
   - 📧 Paste email: =C-y=
   - 📝 Review org entries in =~/Documents/0Inbox/index.org=

:PROPERTIES:
:CUSTOM_ID: keybindings
:END:

*In results buffer:*
| Key | Action |
|-----+--------|
| =c= | Copy email suggestion + create org entries |
| =n= | Next week |
| =p= | Previous week |
| =r= | Refresh |
| =g= | Go to specific week |
| =?= | Help |
| =q= | Quit |

*** Skip specific Google calendars
:PROPERTIES:
:CUSTOM_ID: skip-google-calendars
:END:
Events synced by org-gcal carry their calendar ID in the =entry-id=
property (=EVENTID/CALENDARID=). Calendars listed in
=csf-excluded-gcal-calendars= never block a slot, so calendars that
merely mirror your own tasks can be ignored.
#+begin_src elisp
;; names -> calendar IDs (or a variable holding such an alist)
(setq csf-gcal-calendar-aliases '((tasks . "c_abc123@group.calendar.google.com")))
;; symbols use the aliases; strings are regexps matched against the ID
(setq csf-excluded-gcal-calendars '(tasks "^c_def456"))
;; optional: org entries with no Google entry-id stop blocking too,
;; so only real Google Calendar events count as busy
(setq csf-include-plain-org-entries nil)
#+end_src

** How It Works
:PROPERTIES:
:CUSTOM_ID: how-it-works
:END:

*** The Copy + Create Workflow

When you press =c=:

1. *Email Generation* - Formats the 2 selected slots into a professional email suggestion
2. *Clipboard Copy* - Automatically copies to your clipboard
3. *Org Entry Creation* - Prompts for who the meeting is with
4. *Automatic Insertion* - Creates two tentative meeting entries in your inbox org file

All in one keystroke! ⚡

*** Automatic Org Entry Creation
:PROPERTIES:
:CUSTOM_ID: automatic-org-entry-creation
:END:

When you create org entries with the =c= command:

- Tentative meetings are added to your inbox file (=~/Documents/0Inbox/index.org=)
- Timestamps include both date and time
- Meeting duration is calculated and added to end time
- Name of the meeting contact is included in the heading
- Entries are appended to the end of the inbox file

Example created entries:
#+begin_src org
* Tentative Meeting with John Doe
SCHEDULED: <2025-11-05 Wed 14:30-15:00>

* Tentative Meeting with John Doe
SCHEDULED: <2025-11-06 Thu 14:30-15:00>
#+end_src

** Troubleshooting
:PROPERTIES:
:CUSTOM_ID: troubleshooting
:END:

*** Org entries not being created
:PROPERTIES:
:CUSTOM_ID: org-entries-not-being-created
:END:
- Verify =csf-inbox-file= points to a valid org file
- Make sure the file exists at that location
- Check file permissions

#+begin_src elisp
;; Verify your setting
(message "%s" csf-inbox-file)
#+end_src

*** Can't find free slots
:PROPERTIES:
:CUSTOM_ID: cant-find-free-slots
:END:
- Check that calendar entries exist in your org files
- Try different working hours: =M-x csf-setup-restrictions=
- Reduce minimum slot duration: =(setq csf-min-slot-duration 30)=

*** Python script not found
:PROPERTIES:
:CUSTOM_ID: python-script-not-found
:END:
#+begin_src elisp
(setq csf-python-script-path "/full/path/to/calendar_slot_finder.py")
#+end_src

*** Clipboard not working
:PROPERTIES:
:CUSTOM_ID: clipboard-not-working
:END:
- Linux: Install =xclip= or =xsel=
- macOS/Windows: Should work automatically
